# ParkControl

## Descripción del Proyecto

ParkControl es una aplicación web desarrollada como proyecto académico para gestionar el control de ingreso y salida de vehículos en una cochera.

El sistema permite registrar vehículos, controlar la capacidad disponible, gestionar entradas y salidas, registrar movimientos y administrar promociones basadas en la cantidad de visitas realizadas por los clientes.

Además, el proyecto fue utilizado para aplicar prácticas de control de versiones mediante Git y GitHub, incluyendo ramas, Pull Requests, resolución de conflictos y gestión de releases.

---

## Objetivos

- Gestionar el ingreso y salida de vehículos.
- Controlar la capacidad disponible de la cochera.
- Registrar movimientos de estacionamiento.
- Aplicar buenas prácticas de control de versiones.
- Simular trabajo colaborativo utilizando Git Flow.
